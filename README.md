# 🚗 Real-Time Vehicle Detection and Tracking (Flask + YOLOv8)

This project is a web-based application for **real-time vehicle detection and tracking** using the latest YOLOv8 model and ByteTrack. It runs on **CPU-only environments** and allows users to upload a video to:

- Detect cars, buses, trucks, and bikes.
- Stream processed video live on the web interface.
- Count vehicles using unique tracking IDs (no duplicate counting).


---

## ✅ Features

- 💡 **YOLOv8 + ByteTrack** for real-time tracking
- 🧠 **Unique vehicle counting** with object tracking
- 🌐 **Flask web app** with frontend stream + live stats
- 💻 **CPU-compatible** (no GPU required)
- 📦 Clean modular structure and easy to extend
